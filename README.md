# Java Multithreading Practice

Hands-on Java multithreading practice with small examples and interview-focused problems. This repository is for learning concurrency concepts through coding and building a stronger understanding of how multithreading works in real applications.

## Topics

- Thread creation (`Thread`, `Runnable`, Lambda)
- `ExecutorService`
- Synchronization
- Race conditions
- Producer–Consumer
- Atomic classes
- Locks
- Concurrent collections
- `CompletableFuture`
- Deadlock examples

## Goal

Practice core multithreading concepts and solve common interview-style problems while improving practical Java concurrency skills.
